# 📸 Instagram Clone (Desktop)

A modern **Instagram Desktop Clone** built using HTML, CSS, and JavaScript. This project recreates the desktop version of Instagram with a clean and responsive interface, focusing on UI design, layout structure, and frontend development best practices.

---

## 🚀 Features

- 🏠 Instagram-like Home Feed
- 📖 Stories Section
- ❤️ Like, Comment & Share UI
- 👤 User Profile Sidebar
- 💬 Suggested Users Section
- 🔍 Search Interface
- 📱 Responsive Desktop Layout
- 🎨 Clean and Modern UI
- ⚡ Smooth Hover Effects & Animations

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
